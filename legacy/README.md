# Legacy — Клиника Кота-Доктора

Это сохранённый исходный рабочий прототип проекта «Клиника Кота-Доктора».

Файл `index.html` хранится здесь как backup/reference и не должен удаляться во время постепенной миграции в ПОЧЕМУЧКУ.

## Правило миграции

Сначала сохранить рабочую механику прототипа, затем постепенно переносить её в модульную архитектуру.

Не делать big-bang rewrite без сохранённого legacy-варианта.
