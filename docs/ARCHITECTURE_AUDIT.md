# POCHEMUCHKA — Architecture Audit

Status: Phase 0 / audit pending

This file is the required Phase 0 deliverable for Codex.

## Purpose

Before implementing the MVP, inspect the repository and document:

- current architecture;
- current stack and build system;
- entry points;
- dependencies and scripts;
- reusable code;
- existing prototype behavior;
- Telegram integration;
- deployment;
- assets;
- technical debt;
- risks;
- missing pieces;
- target architecture;
- migration plan;
- files to keep, refactor, or remove.

## Rule

Do not start the big MVP rewrite before the audit is completed and reviewed.

## Codex output

Codex should replace/update this document with the actual findings from the repository audit.
