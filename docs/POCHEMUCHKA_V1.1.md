# ПОЧЕМУЧКИ v1.1

## Цель

v1.1 — слой продуктовой полировки поверх стабильной версии `release/v2.0`.

## 1. Убираем рейтинг

Социальный leaderboard больше не показывается в приложении и не является частью пользовательского маршрута. Прогресс теперь описывается через личные показатели ребёнка: уроки, XP, звёзды, повторение и достижения.

Серверный API leaderboard пока не удалён, чтобы не смешивать UX-изменение с отдельной backend-cleanup миграцией.

## 2. Parent

Статический пример `7 + 5` удалён. Такой gate не является аутентификацией.

Текущий экран — информационный отчёт. Для настоящего родительского кабинета нужен отдельный auth/PIN flow с серверной проверкой.

## 3. Котёнок-Почемучка

Единое имя персонажа: **Котёнок-Почемучка**.

Визуальный образ больше не использует медицинские атрибуты: зеркало, халат, бейдж и стетоскоп.

## 4. Lesson UX

Перед первым заданием ребёнок видит briefing:

- цель урока;
- краткий план;
- кнопку «Начать задания».

После этого сохраняется существующий игровой цикл вопрос → feedback → следующий вопрос → результат.

## 5. Интерактивы

В curriculum добавлены реальные примеры:

- `quiz`
- `matching`
- `drag_drop`
- `sorting`

Первые уроки четырёх миров используют разные интерактивные форматы. Server-side evaluator поддерживает sorting.

## 6. Design System

Добавлен canonical layer с:

- цветовой системой;
- единым focus-visible;
- safe-area для нижней навигации;
- reduced-motion;
- стилями briefing, parent report и sorting activity.

Старые CSS-блоки пока не удалялись массово: это отдельный безопасный refactor, чтобы не смешивать визуальную перестройку с product changes.

## 7. Accessibility

Добавлены:

- видимый keyboard focus;
- aria-label для управляющих кнопок sorting;
- reduced-motion;
- безопасные touch targets;
- safe-area для устройств с home indicator.

## 8. E2E

Playwright проверяет:

1. Home → World → Lesson;
2. briefing перед уроком;
3. interactive activity;
4. завершение урока;
5. parent report;
6. отсутствие пользовательского leaderboard route.

## 9. Mobile QA

Автоматический smoke проходит в Chromium viewport:

- 375 px;
- 390 px;
- 412 px.

Это не заменяет ручную проверку:

- iPhone Safari;
- Telegram WebView;
- Android Chrome;
- desktop Safari/Chrome;
- PWA install;
- offline/cache/update;
- safe-area на реальном устройстве.

## 10. Documentation

README и этот документ описывают текущую архитектуру и ограничения QA.

## Rollback

`release/v2.0`

v1.1 развивается в `main`.
