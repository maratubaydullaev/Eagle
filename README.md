# ПОЧЕМУЧКА

**Узнавай. Играй. Открывай мир!**

Детская образовательная игра/WebApp, развиваемая из существующего прототипа «Клиника Кота-Доктора».

## Документы

- `docs/POCHEMUCHKA_SPEC_v2.md` — основное техническое задание.
- `docs/ARCHITECTURE_AUDIT.md` — результат Phase 0, который должен заполнить Codex.
- `legacy/index.html` — исходный рабочий прототип, сохранённый без изменений.

## Важно

Сначала выполняется архитектурный аудит. Большая миграция начинается только после проверки результата аудита.
